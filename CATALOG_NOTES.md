# Product Catalog Notes

This site is set up to support multiple belt series.

## Add Another Series

1. Put the new brochure PDF in this folder.
2. Render its brochure pages and product preview crops into `assets/pages/`, `assets/products/`, or a source-specific folder such as `assets/range/`.
3. Add a new entry to `seriesCatalog` in `app.js`.
4. Add product objects to `products` with the new `seriesId`.

The current catalog uses:

- `siegling prolink product range.pdf` for range-level series, pitch, surface, and material guidance.
- `forbo engineering manual.pdf` for engineering manual page references.
- `forbo_Ref.no.888-2_1.2_S6.1` for detailed Series 6.1 product pages and images.
- `engineering-data.js`, generated by `scripts/generate_engineering_data.py`, for engineering-manual-backed product cards across the available series.

Run `python scripts/generate_engineering_data.py` after replacing or updating the engineering manual.

Each product should include:

- `id`
- `seriesId`
- `title`
- `category`
- `opening`
- `bestFit`
- `description`
- `materials`
- `temperature`
- `page`
- `image`
- `tags`
- `notes`

Tags should reuse the need IDs near the top of `app.js` when possible so the sales selector continues to recommend products consistently across series.

## Configured Line Items

When a salesperson clicks Configure, the site first uses explicit brochure-derived traits from `brochureTraits` in `app.js`. Add color options there using brochure codes, for example `White (WT)`, `Light blue (LB)`, `Blue (BL)`, `Uncolored (UC)`, `Light gray (LG)`, or `Black (BK)`.

If a future product does not have explicit `brochureTraits`, the site falls back to reading material/color words from the product text. Explicit traits are preferred because brochure tables often list color codes separately from the product summary copy.
